# CarePulse AI – Product Metrics Framework

## 1. Purpose

This document defines the product measurement framework for CarePulse AI.

The framework connects:

**Business Outcome → Product Outcome → User Behavior → Operational Metrics**

The goal is to measure whether the platform is actually improving healthcare monitoring workflows rather than simply generating activity.

---

# 2. North Star Metric

## Timely Clinical Review Rate

**Definition:**

Percentage of high-risk alerts that are acknowledged by an appropriate clinical user within the defined target response time.

### Formula

```text
Timely Clinical Review Rate =
High-risk alerts reviewed within target time
÷
Total high-risk alerts
× 100
